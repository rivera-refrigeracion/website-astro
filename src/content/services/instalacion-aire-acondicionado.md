## Instalación de aire acondicionado a domicilio

Rivera Refrigeración realiza una visita para revisar el equipo, el espacio
disponible y las condiciones del lugar. Presenta el presupuesto antes de
empezar y explica qué incluye. La instalación se realiza solo después de que
usted lo aprueba.

### Qué se revisa durante la instalación

La ubicación de las unidades, el paso de las conexiones y el drenaje se valoran
según el modelo y las condiciones de la vivienda o negocio. El presupuesto
precisa qué incluye el trabajo. Si se requiere una adecuación adicional, se
explica antes de continuar.

### Qué conviene tener listo

Tenga disponible la marca y el modelo del equipo y despeje el acceso al sitio
previsto. Informe si el espacio ya cuenta con alimentación eléctrica y drenaje;
la visita confirma si son adecuados para el equipo. En edificios o locales,
consulte con la administración si se requiere autorización para intervenir una
fachada o área común.

### Tipos de equipos

Rivera Refrigeración trabaja con equipos split, mini split, de ventana y
cassette, además de chillers, sistemas de agua helada para negocios. Cada
sistema tiene requisitos de ubicación y conexión. Rivera Refrigeración revisa
el modelo y el espacio para confirmar el alcance antes de cotizar.

### Tiempo de instalación

Una instalación estándar puede tomar varias horas. El tiempo puede aumentar si
el sitio requiere adecuaciones o un recorrido distinto para las conexiones. La
estimación se entrega después de revisar el equipo y el lugar.

Si el equipo ya está instalado y presenta una falla, consulte el servicio de
[reparación de aires acondicionados en Cali](/servicios/aire-acondicionado/).
